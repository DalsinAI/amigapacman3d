 BUILD
 =====

 Unix: 

 gcc pacman.c pac_ext.c -o pacman -W -Wall `allegro-config --libs --static`

 Windows:

 gcc -c pacman.c -o pacman.o -W -Wall -mwindows
 gcc -c pac_ext.c -o pac_ext.o -W -Wall -mwindows
 gcc -c pac_win.c -o pac_win.o -W -Wall -mwindows
 windres -i pacres.rc -I rc -o pacres_res.o -O coff
 gcc -o pacman.exe pacman.o pac_ext.o pac_win.o pacres_res.o -lalleg -W -Wall -mwindows 

 The code can also be built with using make ('Makefile' on Unix, 'Makefile.win' on Windows).
 (On Windows: make -f makefile.win)
 The Allegro games library (alleg.sf.net) is required to compile the code.
